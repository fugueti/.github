# fugueti/.github

Organization-wide files for [github.com/fugueti](https://github.com/fugueti):

- `profile/README.md` is the organization's public profile page.
- `SECURITY.md`, `FUNDING.yml` and `.github/ISSUE_TEMPLATE/` are the defaults for every repository in the
  organization that has no file of its own (the launcher keeps its own security policy and issue
  templates).
