# Security policy

## Supported versions

Only the latest release of each Fugueti app gets security fixes.

## Reporting a vulnerability

Please **do not** open a public issue. Report it privately in the repository of the affected app:
open its **Security** tab and choose **Report a vulnerability**. You can also e-mail
hello@fugueti.app.

Include the app and its version, the device, the Android version and the steps to reproduce. You
will get an answer within a few days.
